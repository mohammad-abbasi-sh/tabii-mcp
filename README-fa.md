# tabii-mcp 🇹🇷

mcp-name: io.github.mohammad-abbasi-sh/tabii-mcp

سرور MCP غیررسمی و **فقط‌خواندنی** برای tabii.com، پلتفرم استریم TRT (راه‌اندازی ۲۰۲۳، بیش از ۱۱ میلیون مشترک) — سریال‌ها، فیلم‌ها، مستندها و محتوای کودکانهٔ ترکی، و ۱۵ کانال زندهٔ TRT. جست‌وجوی کاتالوگ با عنوان اصلی ترکی، جزئیات کامل هر عنوان (فصل‌ها، قسمت‌ها، بازیگران، زبان‌ها)، آدرس استریم HLS کانال‌های زنده و فیلم‌شناسی بازیگران و عوامل.

> ساختهٔ محمد عباسی در چارچوب «کارخانهٔ MCP ترکیه» (خط تولید به سبک سپهر). وابسته به tabii.com یا TRT نیست.

## برای ایجنت‌های هوش مصنوعی

به پیکربندی MCP client خود اضافه کنید (stdio):

```json
{
  "mcpServers": {
    "tabii": {
      "command": "uvx",
      "args": ["tabii-mcp==0.1.0"]
    }
  }
}
```

یا به‌صورت محلی اجرا کنید: `python -m tabii_mcp.server` (نیازمند `mcp<2` و `curl-cffi`).

## ابزارها

| ابزار | توضیح |
|------|-------|
| `tabii_search_content` | جست‌وجو در کاتالوگ با عنوان اصلی ترکی (مثل «gassal» یا «mevlana») — `language` (پیش‌فرض «tr»، همچنین «en»، «es»، «ar»، «ur»)، `limit` بین ۱ تا ۱۰؛ برای هر نتیجه: id، slug، عنوان محلی‌شده، عنوان اصلی، نوع، سال و URL |
| `tabii_get_show` | جزئیات کامل یک عنوان — `show_id` یا `slug` (مثل «gassal»)؛ عنوان محلی‌شده، عنوان اصلی، نوع، سال، ژانرها، محدودیت سنی، فصل‌ها با عنوان و مدت قسمت‌ها (حداکثر ۶۰ قسمت)، بازیگران، کارگردانان، نویسندگان، توضیح، زبان‌های صدا/زیرنویس، نشان‌ها، تعداد تریلر و URL |
| `tabii_homepage` | بخش‌های فعلی صفحهٔ اصلی (محتوای اختصاصی، سریال، فیلم، مستند، کودک) با عنوان‌هایشان — `language` |
| `tabii_live_channels` | ۱۵ کانال زندهٔ TRT (TRT 1، TRT 2، TRT Belgesel، TRT Haber، TRT Spor، TRT Çocuk، TRT World و…) — آدرس تماشا و آدرس عمومی استریم HLS |
| `tabii_get_person` | یک بازیگر/عضو عوامل با شناسهٔ عددی (مثلاً احمد کورال 6774) — نام، سمت و فیلم‌شناسی او در tabii |
| `tabii_health` | بررسی دسترسی (صفحهٔ اصلی + یک محتوای عمومی) — ok / blocked / error |

نمونهٔ خروجی (`tabii_search_content` / «gassal»، زبان «en»):

```json
{"id": 438813, "slug": "gassal", "title": "The Late Offices",
 "original_title": "Gassal", "content_type": "series", "made_year": 2024,
 "url": "https://www.tabii.com/en/detail/438813/gassal"}
```

## چطور کار می‌کند؟

tabii.com یک API عمومی کاتالوگ دارد که بدون ورود، کلید API و توکن نشست کار می‌کند: `eu1.tabii.com/apigateway/catalog/v1/public/shows/{id}` و `.../public/persons/{id}` (نسخه‌های نیازمند احراز هویت — `search/v1` و `catalog/v1/show/{id}` — بدون توکن Bearer خطای HTTP 401 می‌دهند و استفاده نمی‌شوند). صفحهٔ اصلی با Next.js سمت سرور ساخته می‌شود؛ JSON داخلی `__NEXT_DATA__` بخش‌های ویژه و ۱۵ کانال زنده را با آدرس‌های عمومی HLS در خود دارد. جست‌وجو نقشهٔ سایت را می‌خواند (EN + TR ادغام‌شده: ۱٬۳۰۶ عنوان و ۱٬۱۸۰ نفر — با ۶ ساعت کش) و عنوان‌های محلی‌شدهٔ بهترین تطابق‌ها را از API عمومی می‌گیرد. دو موضوع دور زده نمی‌شود، مستند می‌شود: نقشهٔ سایت کل کاتالوگ را پوشش نمی‌دهد (برخی عنوان‌های دارای مجوز، مثل هابیت، و برخی آثار اصلی غایب‌اند — با شناسه همچنان قابل دسترسی‌اند، مثلاً از بخش‌های صفحهٔ اصلی) و صفحات ژانر/دسته پوسته‌های سمت کاربرند که از یک endpoint نیازمند ورود تغذیه می‌شوند، پس ابزار مرور ژانر ارائه نمی‌شود. پخش به نشست واردشدهٔ Tabii Premium نیاز دارد و خارج از محدوده است — این سرور فقط فرادادهٔ کاتالوگ می‌دهد. انتقال با جعل TLS کروم انجام می‌شود (`curl-cffi`، چرخشی)؛ درخواست‌ها با فاصلهٔ حدود ۰٫۸ ثانیه ارسال می‌شوند؛ همه‌چیز فقط‌خواندنی است.

## نصب

```bash
uvx tabii-mcp==0.1.0        # اجرای مستقیم (نیازمند uv)
# یا
pip install tabii-mcp==0.1.0
tabii-mcp    # سرور MCP را روی stdio راه می‌اندازد
```

## تست‌ها

```bash
python -m venv .venv && .venv/bin/pip install -e .
.venv/bin/python -m unittest discover -s tests -v
```

تست‌های آفلاین با فیکسچرهای ضبط‌شده اجرا می‌شوند (صفحات و پاسخ‌های واقعی API، گرفته‌شده در ۱۱ نوامبر ۲۰۲۶)؛ تست‌های زنده به tabii.com و API عمومی وصل می‌شوند. تست‌ها هنگام ساخت سبز بودند (برای شمار به مخزن نگاه کنید)؛ به‌علاوه یک تست دود MCP روی stdio وجود دارد.

## نقشهٔ راه

- مرور ژانر، اگر tabii روزی endpoint بدون نشست منتشر کند
- فید «تازه‌های این هفته» / تازه‌اضافه‌شده‌ها از بخش‌های صفحهٔ اصلی
- جزئیات در سطح قسمت (توضیح هر قسمت، ترک‌های صدا/زیرنویس)
